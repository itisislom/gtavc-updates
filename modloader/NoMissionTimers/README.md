# NoMissionTimers

Мод для GTA Vice City 1.0: убирает таймеры-провалы в миссиях (через modloader).

## Что внутри

`data/main.scm` — пересобранный вайловый `main.scm` (VC 1.0), в котором убраны
вызовы отображения обратного отсчёта (opcode `014E` / `03C3`) для всех таймеров,
по истечении которых миссия проваливается. Механизм: движок сам уменьшает
переменную таймера, пока она выведена на экран — если убрать вызов отображения,
переменная замирает, условие «таймер == 0» никогда не выполняется, и провала
не происходит.

Оригинальный `data/main.scm` в папке игры не тронут.

| PROTEC1 / PROTEC2 (BUD_1 / BUD_2) | 5 мин |
| BIKE2 (BIKE_2) | 2 мин |
| CUBAN1 (CUB_1) | 3 мин |
| CUBAN4 (CUB_4) | 46 сек |
| HAIT1 (HAT_1) | 2 таймера (61 сек) — гаитяне не бросаются на вас по времени |
| ROCKB1 (ROCK_1) | 91 сек |
| ASSIN3 (JOB_3) | 9 мин |
| TAXWAR1 (TAXI_1) | 61 сек («OUTTIME») |
| TAXI (Taxi Driver) | счётчик fare |
| AMBULAN (Paramedic) | время жизни пациента |
| FIRETRU (Firefighter) | время на пожар |

| BARON1 | скрытый лимит 60 сек (2 проверки `TIMERB > 60000`) |

## Что намеренно оставлено

- **The Shootist (BANKJO2), Gun Range (RANGE), Bloodring (MM), стадионы
  (T4X4_1, CARPRK1), Cabmageddon (TAXWAR3)** — там таймер отсчитывает *раунд*:
  при 0 раунд заканчивается. Если убрать такой таймер, миссия зависает
  (софтлок).
- **Секундомеры гонок** (BANKJO3, BIKE1, OVALRNG, KICKST, RACE, HELI1SC–HELI4SC,
  BMX_1/2, RCHELI, RCRACE1, RCPLNE1) — они ничего не ограничивают, только
  показывают время заезда. В KICKST по нему же считаются призовые ($50 000 за
  5 минут и т.д.), поэтому его не трогаем.

## Побочные эффекты

- В COKERUN «самое быстрое время» теперь записывается как 0 (таймер не тикает).
- В TAXI счётчик fare не убывает — заказ никогда не «сгорает» по времени.
- В HAIT1 гаитяне не начинают охотиться по таймеру (только если вас заметят).

## Откат

Удалить папку `modloader/NoMissionTimers` — и вернётся ванильный `main.scm`.
